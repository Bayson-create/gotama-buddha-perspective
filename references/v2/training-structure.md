# 以三学为骨、以自省为尺：乔达摩先生的修学教练结构

**结论先行：** 乔达摩先生的教练应用，顶层结构直接取自经典：三学（adhisīla / adhicitta / adhipaññā，AN 3.88–3.90）为三大区，八正道按 MN 44 法授比丘尼（Dhammadinnā）的分析归入三蕴，每个道支用 SN 45.8 的操作定义作为"空间"的锚点 [sutta][DB✓]。修学次第以 MN 107 的七步为主线（戒 → 守根门 → 饮食知量 → 警寤 → 正念正知 → 独处与断五盖 → 四禅），但这条主线是出家人的；在家人另有一套经典课程：皈依、五戒、布施、布萨、正当求财用财、善友（AN 8.25、AN 8.54、AN 4.61、AN 8.41–43、DN 31）。"七清净"作为阶梯地图属于觉音《清净道论》（5 世纪，注释层）；在经中它只出现于 MN 24，而且其教义正好反对攀阶：每一站都只是换乘的驿车 [sutta][DB✓]。因此成长标记只记录经典本身要求修行者自查的**过程**：盖障频率、MN 61 三时省察、MN 151 自检、AN 10.53 退/住/增，**绝不颁发证果徽章**。依据有 MN 113、MN 39、AN 10.92、MN 24，以及约束比丘的波罗夷四、波逸提八。计时器可以引用经中的相对时间单位："一挤牛乳顷"（SN 20.4）、"一口食/一呼吸"（AN 6.19）、"夜三分"（AN 3.16）。但**经典从未给出分钟数**，所有分钟值都是应用约定，界面上必须注明。

> 体例：uid 采用 SuttaCentral 编号；"row N" 指 canon.db 的 `rows.id`，"§N" 指 VRI 段号（AN 3 中 VRI 段号比 SC 序号大 1，例如 an3.88 = VRI §89）。层次标签：[sutta] 经，[vinaya] 律，[commentary] 注释（含《清净道论》，5 世纪起），[scholarship] 现代学术。核验状态：**[DB✓]** 已在 canon.db 读到原文；**[title✓]** 只确认了 uid 与标题，内容出自对该经的常识；**未核** 完全未查。本文不引用研究笔记以外的出处。

## 1　三学与八正道分组：顶层结构经典自带

**AN 3.88**（VRI §89，row 770）[sutta][DB✓] 说，每半月诵出的"一百五十余学处"全都摄入三学：增上戒学 adhisīla、增上心学 adhicitta、增上慧学 adhipaññā。同经 row 772 说"**圆满行者成就圆满，部分行者成就部分**"，这是不羞辱用户的进度文案最好的经典框架 ([SC an3.88](https://suttacentral.net/an3.88))。**AN 3.89**（VRI §90，rows 774–777）[sutta][DB✓] 给出定义：增上戒 = 具戒、为别解脱律仪所护；增上心 = 初禅至四禅；增上慧 = 如实知四圣谛。**AN 3.90**（VRI §91，rows 779–782）[sutta][DB✓] 把增上慧改定义为无漏心解脱、慧解脱（āsavakkhaya）([SC an3.89](https://suttacentral.net/an3.89)；[SC an3.90](https://suttacentral.net/an3.90))。

八正道与三蕴的对应出自 **MN 44 Cūḷavedalla §462**（rows 1542–1546）[sutta][DB✓]。毗舍佉问法授比丘尼：是道摄三蕴，还是三蕴摄道？她答**三蕴摄道**：正语、正业、正命属戒蕴；正精进、正念、正定属定蕴；正见、正思惟属慧蕴。row 1544 补充道是有为（saṅkhata）。经末佛陀印可"我也会这样回答"，但这一段笔记未在 DB 中读到，属 [title✓] 程度 ([SC mn44](https://suttacentral.net/mn44))。人格的表述须准确：这个分组是**法授比丘尼的分析、经佛印可**，不是佛陀本人的开示。

各道支的操作定义来自 **SN 45.8 Vibhaṅga**（rows 44–53）[sutta][DB✓] ([SC sn45.8](https://suttacentral.net/sn45.8))：

| 道支 | SN 45.8 定义 | 所属三学（MN 44） |
|---|---|---|
| 正见 | 知四圣谛 | 慧 |
| 正思惟 | 出离、无恚、无害之思惟 | 慧 |
| 正语 | 离妄语、两舌、恶口、绮语 | 戒 |
| 正业 | 离杀、离盗、离非梵行（出家措辞；在家改为离邪淫，AN 8.25 row 257） | 戒 |
| 正命 | 舍邪命 | 戒 |
| 正精进 | 四正勤（未生恶令不生、已生恶令断、未生善令生、已生善令住） | 定 |
| 正念 | 四念处 | 定 |
| 正定 | 四禅 | 定 |

**MN 117 Mahācattārīsaka** [sutta][title✓] 把正见至正命各分为"有漏、属福分、成熟于依著"的世间分，与"圣、无漏、出世间、道支"两种，并指出正见居先，正见、正精进、正念"环绕"每一支 ([SC mn117](https://suttacentral.net/mn117))。这为应用提供了经典依据：每个道支空间既可以作为日常伦理练习，也可以作为道支修习。**DN 22** [sutta][title✓] 的道支定义与 SN 45.8 相同 ([SC dn22](https://suttacentral.net/dn22))。[scholarship] Bhikkhu Bodhi《八正道》也按 MN 44 分组，把修学次序视为戒 → 定 → 慧，同时说明各支并进 ([ATI](https://www.accesstoinsight.org/lib/authors/bodhi/waytoend.html))；此条笔记标注"未实际抓取，凭知识引用"。

## 2　渐次修学：出家七步主线，在家另一套课程

### 出家主线（深度轨）

**MN 107 Gaṇakamoggallāna §74–76**（rows 144–153）[sutta][DB✓] 是最清楚的分步课纲。婆罗门问此法是否有"如数一、二、三"那样的次第学、次第行、次第道，佛答有，"如调马师先调衔勒"。七步依次为：① 具戒、为别解脱律仪所护、于微小罪见怖畏（row 146）；② 守护根门，不取相、不取随相（row 147）；③ 饮食知量，观"非为嬉戏、非为骄逸、非为庄严……唯为此身住"（row 148）；④ 致力警寤（row 149）；⑤ 一切威仪中正念正知（row 150）；⑥ 独处，饭后结跏趺坐，断贪欲、瞋恚、惛沉睡眠（"光明想"）、掉举恶作、疑（row 151）；⑦ 四禅（§76 row 152）。row 153 说：对有学，这些是趣向目标的教诫；对阿罗汉，这些是现法乐住与正念。§77（rows 156–157）有王舍城问路之喻："**如来只是指明道路者**"。§78 row 158 列出佛"不与共住"者的特征：狡诈、不守根门、饮食无度、不勤警寤、失念等，可以直接用作反向清单 ([SC mn107](https://suttacentral.net/mn107))。**AN 3.16 Apaṇṇaka**（rows 74–77）[sutta][DB✓] 把其中三项，即守根门、饮食知量、警寤，称为"无过失道"与漏尽之基础 ([SC an3.16](https://suttacentral.net/an3.16))。

**MN 39 Mahāassapura §416–421**（rows 1340–1345）[sutta][DB✓] 走的是同一条路：惭愧 → 身行清净 → 语行清净 → 意行清净 → 活命清净 → 守根门 → 其后按经文结构依次为饮食知量、警寤、念知、独处、断盖、禅那。它的特色是**每一站都警告自满**："你们或许会想：'这样就够了……'……当还有更高、更应做之事时，愿你们的沙门义不要退失"。每项清净还附带条件："并以那清净的身行，我们将不称扬自己，也不贬低他人"（rows 1341–1342）([SC mn39](https://suttacentral.net/mn39))。这正是里程碑之后教练提示语的经典模板。

**MN 70 Kīṭāgiri §183**（row 478）[sutta][DB✓] 说："我不说初始即能证得究竟智；由次第学、次第行、次第道，方能证得。"并给出十二步：信 → 往近 → 亲近 → 倾耳 → 闻法 → 受持 → 审义 → 思惟忍可 → 欲（chanda）→ 勤 → 衡量（tulanā）→ 精勤 → 以身证真谛、以慧见之。§174（row 461）记佛陀自己不夜食，利益是"少病、少恼、身轻、有力、安住适悦" ([SC mn70](https://suttacentral.net/mn70))。**DN 2 Sāmaññaphala** [sutta][title✓] 是最完整的版本：信与出家 → 小/中/大戒 → 守根门 → 念知 → 知足 → 独处 → 断五盖（负债、疾病、牢狱、奴役、沙漠道五喻）→ 四禅 → 诸智乃至漏尽。**MN 27** [title✓] 次第相同，另有"象迹"警示：弟子要到自己证得之后，才断言"世尊是正等觉者"。两经的段号都未核 ([SC dn2](https://suttacentral.net/dn2)；[SC mn27](https://suttacentral.net/mn27))。**MN 125 Dantabhūmi §215–217**（rows 579–585）[sutta][DB✓] 用调象喻讲同一次第：先拴柱、柔语、给草水，再到戒 → 守根门 → …… → 念处 → 禅；后半部分未读 ([SC mn125](https://suttacentral.net/mn125))。

### 在家轨（默认轨）

在家课程不以禅那为必修，但含随念与慈心。**AN 8.25 Mahānāma**（rows 256–259）[sutta][DB✓] 定义：优婆塞 = 皈依佛法僧；具戒优婆塞 = 持五戒（含离令人放逸的酒类）；自利利他的优婆塞具信、戒、舍、乐见比丘、乐闻法、忆持法、审察义、法随法行八项，并劝他人也这样做 ([SC an8.25](https://suttacentral.net/an8.25))。**AN 8.54 Dīghajāṇu**（rows 567–577）[sutta][DB✓] 的听众是"受用诸欲、妻儿拥挤"的居士。现世四利：勤奋（uṭṭhāna）、守护如法所得之财（ārakkha）、善友、平衡生活（samajīvitā，持秤者喻）。四种漏财：女色、酒、赌、恶友。来世四利：信、戒、舍（"亲手布施，乐于分享"）、慧（见生灭）([SC an8.54](https://suttacentral.net/an8.54))。**AN 4.61 Pattakamma**（rows 452–464）[sutta][DB✓] 讲如法之财的四种"适宜之业"：令自己、父母、家人、雇工、朋友安乐；防火、水、王、贼、继承人；五种供献；供养沙门。第三、四项未读 ([SC an4.61](https://suttacentral.net/an4.61))。

布萨：**AN 8.41/8.42/8.43** [sutta][title✓] 讲八支布萨，即在家人当日"效法阿罗汉"，第三戒改为离非梵行，另加过午不食、离歌舞庄严、离高广大床 ([SC an8.41](https://suttacentral.net/an8.41))。**AN 3.70** [sutta][title✓] 区分牧牛者布萨、尼乾子布萨与圣布萨；圣布萨以随念佛、法、僧、自戒、诸天净化染心（各配洗涤喻），并守八支 ([SC an3.70](https://suttacentral.net/an3.70))。布萨日为每半月第 8、14、15 日，见 AN 3.37 / AN 8.43 偈，段落**未核**。**DN 31 Siṅgāla** [sutta][title✓] 讲关系伦理：四种业染、四种偏私、六种耗财、真友与伪友、六方（父母、师长、妻、友、雇工、沙门）的相互义务 ([SC dn31](https://suttacentral.net/dn31))。**MN 53 Sekha** [sutta][title✓] 值得注意：阿难为释迦族**在家众**讲有学之行，包括戒、守根门、饮食知量、警寤、七善法（信、惭、愧、多闻、精进、念、慧）以及四禅，并用母鸡孵卵作喻 ([SC mn53](https://suttacentral.net/mn53))。由此可见，禅修深度并不排斥在家人，只是不作为在家人的必修项。

## 3　七清净：经中是驿车，论中才是地图

**MN 24 Rathavinīta**（rows 818–852）[sutta][DB✓]：舍利弗逐一问富楼那，是否为戒清净 sīlavisuddhi、心清净 cittavisuddhi、见清净 diṭṭhivisuddhi、度疑清净 kaṅkhāvitaraṇavisuddhi、道非道知见清净 maggāmaggañāṇadassanavisuddhi、行道知见清净 paṭipadāñāṇadassanavisuddhi、知见清净 ñāṇadassanavisuddhi 而修梵行，富楼那逐一答"不是"。row 832 说梵行是"**为了无取般涅槃**"（anupādā parinibbāna）。§259（rows 851–852）用波斯匿王从舍卫城到娑祇多的七乘驿车作喻：每辆车只为到达下一辆 ([SC mn24](https://suttacentral.net/mn24))。七清净在经中基本只见于此经，也没有展开成一套禅修地图。

《清净道论》明确援引 MN 24 [commentary][DB✓]：canon.db `e0102n_mul` row 1628 引 "Rathavinītasuttante … (ma. ni. 1.257) evaṃ paṭipadāñāṇadassanavisuddhīti vuttā"，`e0101n_mul` row 527 提到 "rathavinītapaṭipadaṃ (ma. ni. 1.252)"。**Vism XIV.32** [commentary] 以戒清净、心清净为"根"，以见清净至知见清净五者为"干"；工作次序是先学习、问难，再圆满根，然后发展干 ([wisdomlib Vism](https://www.wisdomlib.org/buddhism/book/visuddhimagga-the-pah-of-purification/d/doc1085140.html)；[theravada.su Vism XIV](https://tipitaka.theravada.su/other/vism/14/part/3/table))。此段原文笔记未直接读取，据搜索摘要与对照本。章节布局 [commentary]（Ñāṇamoli 译，笔记称"标准、未重抓"）如下：

## 5　成长标记：只量过程，不认证果位

经典没有数值评分，所有指标都是应用把经中的自省问题操作化的结果，界面应当照实说明 [笔记缺口]。下列标记全部由用户自报，各自挂在一件经典"工具"上。

**心镜十问（AN 10.51 Sacitta，rows 368–372）[sutta][DB✓]。** 用净镜或水钵照面的比喻，问十项"我是否常住于……"：贪/不贪、瞋/不瞋、惛沉睡眠、掉举、疑、忿、心染、身躁动、懈怠/精进、不定/定。逐项是/否，汇总为心镜分。多数为负向时，按经文"如头燃、衣燃"般生起欲、精进、念、正知；多数为正向时，安住于善，再求漏尽 ([SC an10.51](https://suttacentral.net/an10.51))。AN 10.52（舍利弗说，同一教法）与 AN 10.54（止/观有无四句）为 [title✓]。

**三时省察日志（MN 61，rows 289–302）[sutta][DB✓]。** §109 问"镜子有什么作用？为了省察"。每一身行在事前、事中、事后各问一次：是否导致自害、他害、俱害？事前若有害则不做，事中若有害则停，事后若有害则向师长或有智同修发露、往后防护，若无害则"日夜随学而住"于喜悦。§110 讲语行同理。§111 讲意行：事后无从发露，应"厌患、羞愧、厌恶"并防护 ([SC mn61](https://suttacentral.net/mn61))。记录方式：日志数分事前/事中/事后三类。**破戒后的修复计为进步**，因为 AN 3.88 row 771 说具足者仍可能犯小戒并出罪 [DB✓]。

**周度自检（MN 151 Piṇḍapātapārisuddhi，rows 1282–1297）[sutta][DB✓]。** 在家版把"乞食路"转译为通勤或日常路线，这是推论。逐项问：是否对色、声、香、味、触、法起欲、贪、瞋、痴、厌？是否已断五欲（§440）、五盖（§441）？是否遍知五蕴（§442）？是否修习了四念处（§443）、四正勤（§444）、四神足（§445）、五根（§446）、五力（§447）、七觉支（§448）、八圣道（§449）、止与观（§450）？"否"则精勤，"是"则日夜喜乐随学 ([SC mn151](https://suttacentral.net/mn151))。**计分只用前 12 项；§451"是否已证明与解脱"（row 1296）不计分**，只作为私人省思提示或直接省略。

**盖障追踪（AN 5.193 Saṅgārava，rows 1146–1155；SN 46.51 Āhāra，rows 583–595）[sutta][DB✓]。** 五盖每次或每天按 0–4 自评，看趋势。AN 5.193 提供自我描述的意象：欲贪是染色之水，瞋恚是沸水，惛沉是苔草覆盖的水，掉悔是风起涟漪，疑是暗处浊水；无盖时水清，"连未诵过的文句也会浮现" ([SC an5.193](https://suttacentral.net/an5.193))。SN 46.51 提供"食"标签：欲贪食于净相，瞋食于瞋相，惛沉食于不乐、懒倦、欠伸、食后困、心沉，掉悔食于心不寂静，疑食于疑处，皆由不如理作意喂养。断食之法：row 595 为不净相对欲贪；其余几项（慈心解脱对瞋、发起界对惛沉、心寂静对掉悔、如理作意于善不善对疑）出自标准经文，相应 rows 未读 ([SC sn46.51](https://suttacentral.net/sn46.51))。"频率"指标本身是应用推论，经中没有数值化的盖障"比率" [笔记缺口]。

**退·住·增月检（AN 10.53 Ṭhiti，rows 381–383；AN 7.68，rows 492–495）[sutta][DB✓]。** "于诸善法，我不称赞住立，更何况是衰退！我只称赞增长。"按信、戒、闻、舍、慧、辩才六法逐月自评退、住或增。AN 7.68 的"知自己"也盘点同样六法 ([SC an10.53](https://suttacentral.net/an10.53)；[SC an7.68](https://suttacentral.net/an7.68))。佛只赞增长，所以教练可以在"住"时温和地推一把。

**每日五念（AN 5.57，rows 369–379）[sutta][DB✓]。** 经文明说"应由女人或男人、在家者或出家者时常省察"。五念为老、病、死、与一切所爱别离、业为己有，分别对治少壮骄、无病骄、寿命骄、对所爱的欲贪、恶行；把五念推广到"一切众生"，则"道便生起" ([SC an5.57](https://suttacentral.net/an5.57))。记录：每日完成与否。

其余辅助标记：按类型统计的禅修次数与分钟数，以及 SN 46.51/SN 20.4 所说慈心三时段；在家人的布萨日持守次数；AN 4.94 止/观两轴自我定位 [DB✓]。

## 6　每日修学结构：经给时段与单位，应用给分钟

### 经中的时间骨架

**夜三分与警寤**（AN 3.16 row 77 与 MN 107 row 149，逐字平行）[sutta][DB✓]："白日经行、宴坐，从诸障碍法中净化其心；夜间初更，经行、宴坐…；夜间中更，右胁而卧，行狮子卧，足与足交叠，具念正知，作意起身之想；夜间后更，起身之后，经行、宴坐。"MN 107 row 151 讲饭后归来结跏趺坐、于面前建立念；MN 151 row 1283 与 MN 61 row 289 讲"于傍晚时分"出独住，随后论法或教诫 [DB✓]。由此得到一个出家日的骨架。经中没有钟点时刻表，"凌晨四点起床"之类属后世寺院惯例 [笔记缺口]。注释书把三更各折算约四小时，此条**未核**，归入 [commentary]/惯例。

**经行**（AN 5.29 Caṅkama，row 128）[sutta][DB✓]，五利益：堪远行、堪精勤、少病、饮食易消化、经行所得之定久住 ([SC an5.29](https://suttacentral.net/an5.29))。

**慈心**：SN 20.4 Okkhā §226 row 1239 [sutta][DB✓]，晨、午、晚各施百釜食，福不及于晨、午或晚修慈心"**乃至仅一挤牛乳顷**"（gaddūhanamattaṃ）。这给出一日三时段（pubbaṇha / majjhanhika / sāyanha），以及一个最小单位 ([SC sn20.4](https://suttacentral.net/sn20.4))。AN 11.15 rows 145–146 [DB✓] 列慈心解脱十一利益：眠安、觉安、不见恶梦、人爱、非人爱、天护、火毒刀不侵、心速得定、面色明净、临终不昧、未通达则生梵天 ([SC an11.15](https://suttacentral.net/an11.15))。Snp 1.8 [title✓] 有"行住坐卧，乃至未睡（yāvatāssa vigatamiddho），当立此念"。AN 1.53–55 的"一弹指顷"慈心**未核** ([SC an1.53-60](https://suttacentral.net/an1.53-60))。

**随念**：AN 6.10 Mahānāma rows 37–39 [sutta][DB✓]，对在家人摩诃男讲六随念（佛、法、僧、自戒、自舍、天）；修习时"其心不为贪、瞋、痴所缠……心正直" ([SC an6.10](https://suttacentral.net/an6.10))。AN 11.12 [title✓，段落未核] 说"行、住、坐、卧、工作中、在妻儿拥挤的家中"皆可修 ([SC an11.12](https://suttacentral.net/an11.12))。**死随念**：AN 6.19 rows 107–117 [sutta][DB✓]，比丘们报告以一日一夜、一餐、半餐、四五口、一口、一呼吸为时长修死念，佛说长者为放逸，唯"一口食"（row 117）与"一呼吸"者为不放逸 ([SC an6.19](https://suttacentral.net/an6.19))。AN 6.20 [title✓] 讲晨昏检查：若今夜死去，哪些不善法会成为障碍 ([SC an6.20](https://suttacentral.net/an6.20))。

**安般念**：MN 62 §119–121 rows 310–321 [sutta][DB✓] 讲坐于林中、树下或空屋，于面前立念；row 321 说修安般者临终最后的呼吸是知而灭，非不知而灭。同经还有地、水、火、风、空五界修习，以及慈、悲、喜、舍分别断瞋、害、不乐、瞋碍；不净断贪与无常想断"我慢"两项出自标准经文，row 315 截断 ([SC mn62](https://suttacentral.net/mn62))。MN 118 [title✓] 以四组十六步讲安般念满四念处，四念处满七觉支，七觉支满明与解脱；背景是自恣满月，佛陀把雨安居延至第四月的迦提满月 ([SC mn118](https://suttacentral.net/mn118))。**七年至七日**：MN 10 §137 rows 398–399 / DN 22 §404 rows 1175–1177 [sutta][DB✓] 说，"如是"修四念处，七年乃至七日，可预期（pāṭikaṅkha）二果之一 ([SC mn10](https://suttacentral.net/mn10))。

## 结论

这套结构最有价值的地方，是经典的自省工具与反徽章立场本来就是同一套东西。MN 61 的镜子、AN 10.51 的水钵、MN 151 的乞食路自检，问的都是"今天心里出现了什么"，从不问"你到了第几层"；MN 24 的驿车、MN 39 的"还有更高"、MN 113 的不认同初禅，又从另一侧堵住了把过程变成名次的路。因此应用不需要在"有成长感"和"不违法义"之间取舍：只要指标停留在过程层、修复计为进步，并且如实说明分钟和分数都是应用约定，教练就既有可见的进展，又不越过"如来只是指明道路者"这条线。
